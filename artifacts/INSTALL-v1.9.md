# FART CREW 1.9

Install `Fart-Crew-v1.9-debug.apk`. New installs automatically connect to `wss://fc-game.onrender.com`; players do not need to enter a server address. All sound, boat colour and mobile view changes from 1.8 are included.

An existing saved custom server address is preserved when upgrading. To switch an older installation to the online default, clear Settings > Multiplayer server > Server address and tap Save Server once. New users do not need this step.

The free Render server may take about a minute to wake after inactivity. The app needs internet access, and crew voice still needs the deployed TURN configuration.
